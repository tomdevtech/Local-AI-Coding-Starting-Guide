# Coding Idea Buddy Skill

## Purpose
Get creative coding ideas, learn new patterns, and get help when you're stuck on what to build next.

## Getting Started

### 1. Brainstorming Ideas

```
I want to build a project that does [describe idea]. Can you suggest:
- Features I should include
- A simple tech stack for this
- Step-by-step plan to get started
```

### 2. Learning New Patterns

```
Show me examples of how to do [feature] in Python/JavaScript/etc.
I'm a beginner, so please explain each part clearly.
```

### 3. Getting Unstuck

```
I'm stuck on this problem: [describe the issue]
Can you give me a hint or show me an example?
```

## Beginner Tips

- **Start with small projects**: To-do lists, calculators, simple games
- **Copy and modify**: Learn by looking at working examples, then changing them
- **Ask for explanations**: "Why does this work?" is always a good question
- **Build incrementally**: Add one feature at a time

## Example Workflow

1. Tell the AI what you want to build (even if it's vague)
2. Ask: "What are 3 simple features I could start with?"
3. Build one small feature first
4. Ask: "How can I add another feature on top of this?"
