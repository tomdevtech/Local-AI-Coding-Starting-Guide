# Orchestrator Skill

## Purpose
Plan and execute complex coding tasks by breaking them into manageable steps. Perfect for beginners who need help organizing their workflow.

## Getting Started

### 1. Task Planning

```
I want to build [project description]. Help me break this down into:
- Step-by-step plan
- What to do first
- How to track progress
```

### 2. Workflow Coordination

```
Here's my current workflow:
[list your steps]

Can you suggest improvements? Where might I get stuck?
```

### 3. Multi-Tool Coordination

```
I need to use multiple tools (e.g., terminal commands, code editing, testing).
Help me coordinate the order and what to do at each step.
```

## Beginner Tips

- **Break things down**: Large projects feel scary — split them into tiny steps
- **One step at a time**: Complete one task before moving on
- **Check your work**: After each step, verify it's working correctly
- **Use checklists**: Keep track of what you've done and what's next

## Example Workflow

1. Tell the AI about your project goal
2. Ask: "Break this into 5 small steps"
3. Complete step 1 and test it
4. Ask: "What should I do for step 2?"
5. Repeat until the project is done
