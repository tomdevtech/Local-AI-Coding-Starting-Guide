# Code Analyzer Skill

## Purpose
Learn to analyze your own code with AI assistance, find bugs, suggest improvements, and understand complex logic.

## Getting Started

### 1. Analyze a Function

Ask the AI to explain what a function does:

```
Analyze this function for me:
[paste function code here]

Please tell me:
- What it does in plain English
- Any potential bugs or edge cases
- How to test it
```

### 2. Find Bugs

```
I have this code and I'm getting an error:
[code + error message]

Help me understand what's wrong and how to fix it.
```

### 3. Suggest Improvements

```
Here's my code. Can you suggest improvements?
[code]

Focus on: readability, performance, and best practices.
```

## Beginner Tips

- **Start small**: Analyze one function at a time
- **Be specific**: Tell the AI what kind of help you want (bugs, optimization, explanation)
- **Iterate**: Ask follow-up questions like "Can you explain that fix?" or "What if I change this parameter?"
- **Learn from suggestions**: Don't just copy, understand why a suggestion was made!

## Example Workflow

1. Paste your code into the AI chat
2. Ask: "Explain this to me as if I'm a beginner"
3. If something is unclear, ask: "Can you show an example?"
4. Try the suggested fix and test it yourself
