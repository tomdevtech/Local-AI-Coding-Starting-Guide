# Coding QA Skill

## Purpose
Get clear, beginner-friendly explanations of coding concepts. Ask "why" and "how" questions to truly understand the material.

## Getting Started

### 1. Concept Explanation

```
Explain [concept] to me like I'm a complete beginner.
Examples: variables, functions, loops, classes, APIs, etc.
```

### 2. Error Debugging

```
I get this error when I run my code:
[error message]

What does it mean and how do I fix it?
```

### 3. Comparison Questions

```
What's the difference between [concept A] and [concept B]?
Which one should I use for [your specific case]?
```

## Beginner Tips

- **Ask "why"**: Don't just accept answers — ask why something works a certain way
- **Use examples**: Always ask for code examples to illustrate concepts
- **Build up knowledge**: Start with basics before moving to advanced topics
- **Test your understanding**: After learning, try writing code yourself

## Example Workflow

1. Ask about a concept you don't understand
2. Request a simple code example
3. Try the example yourself and modify it
4. Ask follow-up questions as needed
