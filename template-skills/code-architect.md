# Code Architect Skill

## Purpose
Learn to design clean, well-structured projects using AI as a thinking partner. Focus on organization, patterns, and best practices.

## Getting Started

### 1. Project Structure Review

```
Show me how I should organize this project:
[paste your folder structure]

Please suggest improvements for readability and maintainability.
```

### 2. Naming Conventions

```
Here are my file names:
[list of files/folders]

Are these following good naming conventions? Suggest improvements if needed.
```

### 3. Module Boundaries

```
I have this function that does too much. Can you help me split it into smaller modules?
[code]

Please explain the reasoning behind each split.
```

## Beginner Tips

- **Start with a simple structure**: Don't over-engineer early on
- **Use consistent naming**: Variables, functions, and files should follow clear patterns
- **One file, one responsibility**: Each file should have a single purpose
- **Ask "why"**: When the AI suggests a change, ask why it's better

## Example Workflow

1. Show your project structure to the AI
2. Ask: "How would you organize this for a beginner?"
3. Implement the suggested structure step by step
4. Ask: "Does this make sense? Can you explain each part?"
